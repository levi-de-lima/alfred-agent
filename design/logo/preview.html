Alfred — logo final

Wyvern de Wessex + wordmark "ALFRED" em Cinzel Bold (caixa alta romana). Cor primária #0066FF. Três variantes de cor para cobrir todos os contextos de uso.

Como o sistema funciona: a variante blue é o asset oficial (default). As variantes white e black existem como exports estáticos para contextos onde CSS não pode trocar a cor (impressão, e-mail HTML, PDF embutido, fundo TMB Blue). Para o app em si, o ideal é importar o SVG e trocar fill via currentColor + var(--brand-accent) dos tokens — assim o mesmo arquivo se adapta automaticamente ao tema.

Observação: em fundo escuro, o azul #0066FF tem contraste apertado (~5.3:1) e pode "vibrar" para alguns olhos. Por isso a recomendação dos tokens é usar #4D8FFF no tema dark — mas isso só funciona via CSS. Se você precisar do SVG estático em fundo escuro (e-mail, PDF), use a variante white.
